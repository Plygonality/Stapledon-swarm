# Launch reference

[`lightsail.py`](lightsail.py) reprints the adopted laser-driven lightsail family. [`check_consistency.py`](check_consistency.py) checks geometry, boost integrals, coast years, and the README binding table. Stdlib only. Neither script is a swarm simulator and neither models braking.
